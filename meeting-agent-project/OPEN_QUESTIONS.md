# Open Product Questions

These questions are intentionally unresolved.

## Product

1. Is the long-term product primarily a meeting agent or a broader team workspace?
2. Which user segment is the narrowest useful initial wedge?
3. Which single workflow is the MVP's hero workflow?

## Agent

4. How much should the agent act without confirmation?
5. Should users be able to configure risk policies?
6. When should the agent proactively interrupt the user?
7. How should conflicting user preferences be resolved?

## Team

8. What does a "team" mean in the product?
9. Should members have individual agent identities?
10. Should agents negotiate directly?

## Inbox

11. Is Inbox primarily communications, approvals, or operational attention management?
12. Should email be integrated into Inbox or remain separate?

## Meeting intelligence

13. Is live meeting intelligence in scope?
14. What meeting data can be retained?
15. Which sources are used for meeting preparation?

## Architecture

16. Central orchestrator vs multiple specialized agents?
17. Which LLM provider?
18. Which database?
19. Which frontend stack?
20. Which backend stack?

## Business

21. What is the monetization model?
22. What is the differentiating moat?
23. Which capabilities require paid integrations?

## Trust

24. What is the default risk policy?
25. What is the exact audit trail shown to users?
