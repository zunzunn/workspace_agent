# Agent Memory

## Types of memory

### Explicit preferences

Examples:
- no meetings before 10 AM
- 15-minute buffer
- lunch protection
- preferred meeting duration
- preferred meeting days

### Team context

- team definitions
- project membership
- recurring meeting purpose

### Operational memory

- prior meeting decisions
- unresolved action items
- follow-up commitments

## Memory rules

- explicit user preferences should be distinguishable from inferred patterns
- inferred preferences should be presented as suggestions until confirmed
- sensitive data should not be stored unnecessarily
- users should be able to inspect important persistent preferences

## Example

Agent:
> "You usually prefer 15-minute buffers between meetings. Should I make that your default scheduling preference?"

This is preferable to silently changing a permanent rule.
