# Meeting Lifecycle Intelligence

## Before

The agent can:
- identify participants
- inspect authorized context
- generate agenda
- surface unresolved issues
- create a preparation brief
- remind the user of previous commitments

## During

Future capabilities:
- transcript ingestion
- decision detection
- action item extraction
- question tracking

## After

The agent can:
- summarize
- extract decisions
- extract action items
- identify owners
- draft follow-up
- propose next meeting

## Lifecycle object

A meeting should connect:
- calendar event
- participants
- purpose
- agenda
- context
- notes
- decisions
- actions
- follow-up

## Product advantage

This turns the calendar event into a persistent work object.
