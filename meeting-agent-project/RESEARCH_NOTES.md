# Research Notes

## Product insight

The strongest conceptual shift is:

> Calendar management is a tool capability. Meeting lifecycle management is the product.

## UX insight

The supplied visual reference shows a useful pattern:
- concise agenda summary
- clear time
- direct "view" action
- direct "join" action
- friendly but restrained copy

This should influence the dashboard without copying the reference literally.

## Agent insight

Reliability is more important than the number of agents.

A system with one orchestrator and strong tools can be more genuinely agentic than a chain of four poorly bounded agents.

## Product insight

The "wow" moment should involve multiple dependent actions:
- understand intent
- identify people
- inspect calendars
- apply constraints
- propose
- get approval
- execute
- verify
- produce useful meeting context

## Product risk

Scope explosion is currently the largest planning risk.
