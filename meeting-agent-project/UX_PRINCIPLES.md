# UX Principles

## 1. Calm over complexity

The interface should feel like a professional workspace, not an AI control panel.

## 2. Progressive disclosure

Default view:
- what matters
- what changed
- what needs attention

Details should be expandable.

## 3. Actionable cards

Use compact cards inspired by the provided visual reference:
- event title
- time
- participants
- status
- one or two clear actions

## 4. Show progress for long operations

Example:

- Understanding request ✓
- Checking calendars ✓
- Finding candidate times ✓
- Preparing recommendation →
- Waiting for approval ○

## 5. Approval should be concrete

Instead of:
> "Do you want me to proceed?"

Show:
> "Create 'Project X Sync' tomorrow at 2:30 PM with 6 participants?"

Actions:
- Approve
- Change time
- Edit attendees
- Cancel

## 6. Explain consequential choices

When the agent selects a slot:
- show why it fits
- show relevant constraints
- avoid exposing unnecessary chain-of-thought

## 7. Never hide mutations

Every change should be visible:
- before
- proposed
- approved
- executed
- failed

## 8. Visual direction

The supplied reference suggests:
- clean light interface
- rounded cards
- compact typography
- strong information hierarchy
- minimal clutter
- direct action links/buttons
