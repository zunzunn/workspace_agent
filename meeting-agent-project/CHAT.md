# Group Chat and Agent Interaction

## Purpose

Group chat is a team communication surface that can optionally include the Meeting Agent.

## Examples

User:
> @MeetingAgent find a time for everyone next week.

Agent:
> I found three common slots. Wednesday 2 PM has the fewest conflicts. Should I propose it?

## Agent participation rules

The agent should not:
- interrupt conversations unnecessarily
- expose private calendar details to unauthorized members
- reveal another user's private availability details

## Privacy-aware response

Instead of:
> "Rahul is at a doctor appointment."

Say:
> "Rahul is unavailable at that time."

## Future capability

A group chat could become a natural interface for team-level scheduling.
