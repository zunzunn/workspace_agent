# Product Scope

## Core

The first coherent product should center on:

**Natural-language meeting coordination + calendar intelligence + approval-based execution.**

## In scope for an initial vertical slice

1. Google OAuth
2. Calendar read access
3. Calendar search
4. Availability analysis
5. Natural-language scheduling request
6. Candidate slot generation
7. Conflict explanation
8. Approval UI
9. Calendar event creation
10. Event modification
11. Dashboard agenda
12. Meeting detail
13. Basic meeting preparation
14. Action/audit history

## Next layer

- Team management
- Shared team context
- Inbox
- Group chat
- Meeting follow-up
- Gmail context
- Google Meet integration
- Recurring-meeting intelligence
- Calendar cleanup
- Proactive suggestions

## Later / advanced

- Individual agent identities
- Agent-to-agent scheduling negotiation
- Rich organizational graph
- Live meeting intelligence
- Cross-tool task execution
- Proactive meeting lifecycle automation

## Scope warning

Do not implement all advanced features simultaneously. The architecture should leave room for them without making the MVP dependent on them.
