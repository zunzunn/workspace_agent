# Definition of Done

A feature is not complete until:

## Product
- [ ] User problem is clearly addressed.
- [ ] UX states are designed.
- [ ] Success and failure states exist.

## Engineering
- [ ] Backend implementation complete.
- [ ] Frontend implementation complete.
- [ ] Database changes complete.
- [ ] Authorization complete.
- [ ] Secrets handled securely.

## Agent
- [ ] Tool contracts defined.
- [ ] Agent behavior documented.
- [ ] Ambiguity behavior defined.
- [ ] Approval behavior defined.
- [ ] Verification implemented.

## Quality
- [ ] Unit tests.
- [ ] Integration tests.
- [ ] Relevant end-to-end test.
- [ ] Error cases tested.

## Operations
- [ ] Logs/metrics sufficient to debug.
- [ ] No sensitive secrets in logs.
- [ ] Documentation updated.
