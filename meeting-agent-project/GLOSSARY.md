# Glossary

## Agent
The AI system that interprets requests, plans actions, uses tools, and reports results.

## Orchestrator
The component responsible for coordinating agent steps and tool execution.

## Tool
A controlled callable interface to an external system or internal service.

## Mutation
An action that changes state, such as creating or deleting a calendar event.

## Proposal
A planned action shown to the user before execution when approval is required.

## Verification
Checking the authoritative system after a mutation to confirm the intended state exists.

## Meeting lifecycle
Before → Schedule → During → After → Follow-up.

## Organizational context
People, teams, roles, projects, and relationships relevant to work.

## Approval
Explicit user authorization to perform a consequential action.

## Tenant
An isolated organization/workspace boundary.
