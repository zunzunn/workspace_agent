# Privacy

## Data categories

Potentially processed:
- calendar metadata
- attendee identities
- meeting descriptions
- team information
- chat messages
- email context
- meeting notes

## Principles

- collect only necessary data
- minimize retention
- make integrations explicit
- provide disconnect controls
- explain what the agent can access
- make AI-generated context distinguishable from source data
- allow users to inspect important data usage

## Product trust

The UI should clearly communicate:
- which account is connected
- which data source is being used
- what information is being retrieved for a task
- what action will occur
