# Development Workflow

## Planning loop

For every feature:

1. Define user outcome.
2. Define acceptance criteria.
3. Define tool/API requirements.
4. Define data changes.
5. Define UI states.
6. Define failure states.
7. Implement.
8. Test.
9. Verify end-to-end.
10. Document.

## Agent-assisted development

When delegating to a coding agent:
- give it the relevant MD files
- define a bounded task
- require tests
- require a summary of changed files
- require verification commands
- inspect before moving to the next task

## Feature completion checklist

- [ ] frontend
- [ ] backend
