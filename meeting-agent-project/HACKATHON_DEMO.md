# Hackathon Demo Plan

## Objective

Demonstrate a complete agentic workflow in a short amount of time.

## Suggested demo

User types:

> "I need everyone working on Project X to meet tomorrow. Find a time, schedule it, prepare an agenda based on our previous meetings, and leave 15 minutes between the meeting and my other events."

## Demo flow

1. Agent interprets request.
2. Resolves Project X members.
3. Reads authorized calendars.
4. Finds candidate slots.
5. Explains selected slot.
6. Presents approval card.
7. User approves.
8. Agent creates meeting.
9. Verification confirms event.
10. Dashboard updates.
11. Meeting page shows generated agenda.

## Visual moment

Show an activity timeline:

```text
✓ Understood request
✓ Found 6 Project X members
✓ Checked calendars
✓ Found 3 possible times
✓ Applied 15-minute buffer
✓ Prepared agenda
→ Waiting for approval
```

Then:

```text
✓ Meeting created
✓ 6 participants invited
✓ Calendar verified
```

## Important

The demo should show actual tool execution, not simulated "AI" status messages.
